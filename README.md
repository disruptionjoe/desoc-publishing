# desoc-publishing

An AI-native research publishing system where orthodox and heterodox ideas
compete on evidence rather than institutional permission.

This public repository begins in Phase 0. It is both an application project and
a proving ground for whether agents can move from a founder's purpose and
feedback to useful, continuously improving software with limited human
attention.

## Founding direction

- Producers should be able to publish simple research artifacts without an
  institutional gatekeeper, establish meaningful priority, remain
  pseudonymous when appropriate, and later prove authorship.
- People and agents looking for research should be able to navigate an open
  corpus through plural, explainable views rather than one mandatory ranking.
- Correlated attention, disagreement, and suspected manipulation should become
  legible evidence, not automatic grounds for deletion.
- Markdown and linked, agent-legible knowledge are the likely native medium.
  The human interface should remain minimalist and usable.
- The exact first product is deliberately unresolved. Phase 0 must earn it
  through research and bounded local experiments.

The repository is public and MIT-licensed from its founding commit. No
user-facing service, live submissions, production data, identity system, or
decentralized backend exists yet.
